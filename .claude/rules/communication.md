# Communication

- Do not use emojis in messages or code unless explicitly asked
- When reporting information to me, be extremely concise and sacrifice grammar for concision.
- Define acronyms on first use — spell out the full term with the acronym in parentheses (e.g. "Denial of Service (DoS)"), then use the short form. Applies to anything a general CS person wouldn't know; skip ubiquitous ones (API, URL, HTTP).

## Session Management

- If the session hasn't been renamed after the first substantive exchange, suggest a short descriptive name using `/rename` (e.g., `/rename fix_auth_retry`). This helps the user keep terminal tabs organized.
